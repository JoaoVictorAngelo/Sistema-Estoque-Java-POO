# Sistema de Estoque e Vendas - Java POO

Projeto desenvolvido em Java para gerenciamento de estoque e vendas, aplicando conceitos de Programação Orientada a Objetos (POO).

## 📌 Sobre o projeto

O sistema foi desenvolvido como parte do Projeto Integrado III da UNIFEOB, com o objetivo de aplicar na prática os principais conceitos de Programação Orientada a Objetos utilizando Java.

O projeto permite trabalhar com produtos, estoque, clientes, fornecedores, vendedores, entradas de estoque e vendas.

## 🚀 Funcionalidades

* Cadastro e gerenciamento de produtos
* Controle de estoque
* Entrada de produtos no estoque
* Verificação de estoque mínimo
* Cadastro de clientes
* Cadastro de fornecedores
* Cadastro de vendedores
* Registro de vendas
* Controle dos itens vendidos
* Atualização da quantidade em estoque

## 🧱 Conceitos de POO

Durante o desenvolvimento foram utilizados conceitos como:

* Classes e objetos
* Encapsulamento
* Herança
* Polimorfismo
* Abstração
* Construtores
* Getters e Setters
* ArrayList
* Enum
* Sobrescrita de métodos
